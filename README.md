# Unstick (prototype)

One small task to help you start when you feel creatively stuck. This is a design prototype, not a finished product.

**Open it:** https://YOUR-USERNAME.github.io/YOUR-REPO/  (replace with your own)

**Presenting?** Add `?demo=1` to the address to show a small "tools" button (speed up timers, fill sample data, simulate three days later, ask "what do you think will happen?" before each task).

**What is real and what is not**
- Everything is saved only in your own browser. There is no server.
- Sign up and the wall are concepts: nothing is sent, shared or charged.
- A web page cannot lock a phone. The phone lock only works inside the app screen.

**On a phone:** open the link in Safari or Chrome, then Share > Add to Home Screen.
